ÅBN HJEMMESIDEN:
1. Dobbeltklik på index.html.
2. Vælg Safari, hvis macOS spørger.

VIGTIGT:
- Slet eller omdøb ikke mapperne assets/css, assets/js eller assets/images.
- Favicon-filerne skal blive liggende ved siden af index.html.
- Hele denne mappe kan senere uploades til et webhotel.

index.html
assets/css/style.css
assets/js/app.js
assets/images/
